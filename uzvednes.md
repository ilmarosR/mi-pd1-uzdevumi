# Uzvednu šabloni - PD1

## Uzdevuma apraksts

```text
Loma: Tu esi pieredzējis timekla lietotnu izstradatajs.

Měrķis: izveidot uzdevumu saraksta timekla lietotni "Mani uzdevumi".

Tehnologijas: tirs HTML, CSS un JavaScript, bez bibliotekam.

Lietotnes tris koda faili: index.html, style.css, app.js.
Lietotnei jadarbojas, atverot index.html parlükã, bez servera un interneta.

Funkcijas:
1. Pievienot uzdevumu ar pogu "Pievienot" vai Enter. Pēc pievienošanas ievades lauks ir tukšs. Atstarpes teksta sākuma un beigs nonem. Tukšu tekstu vai tikai atstarpes nepievienot.
2. Atzimēt uzdevumu kā izpilditu ar izvěles rütinu (izsvitrots teksts), atkārtots klikškis atcel atzimi.
3. Dzěst uzdevumu - katrai rindai sava dzěšanas poga.
4. Filtrs: Visi / Aktivie / Izpilditie; izvēlētă poga vizuāli izcelta.
5. Skaititajs "Atlikuši N uzdevumi", atjaunojas pēc katras darbibas.
6. Dati saglabajas localStorage ar atslēgu "pdl-uzdevumi" (JSON).

Elementu ID: <hl> "Mani uzdevumi", task-input (vietturis "Jauns uzdevums..."),
add-btn, task-list (<ul>), counter (<span>); filtru pogãm atributs data-filter.

Datu struktüra: masivs ar objektiem { id, text, done }; id ir unikäls

Ierobežojumi: saskarne un komentāri latviešu valodă, teksta attēlošanai
lieto textContent, neviena funkcija nav garaka par 30 rindãm, konsole nedrikst but kludu, jadarbojas Chrome un Firefox.

Izvades formäts: katrs fails atseviška koda bloka ar faila nosaukumu.
Pēc koda 3 teikumos paskaidro, kã palaist.
Ja kaut kas nav skaidrs, pirms koda uzdod man jautäjumus.
```
